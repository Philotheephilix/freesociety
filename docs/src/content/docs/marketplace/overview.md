Errand began by closing one gap: Swiggy Money gift cards were delivered by
Bitrefill but had no API or website path to redeem them. We built the missing
piece, and an agent could complete the purchase end to end. The marketplace is
that same move, offered to any company.

If your company has a job that an AI agent should be able to do — but there is no
MCP integration for it — you request it here. Our developers build the
integration into the hub. Your agents then drive it like any other `*__*`
passthrough tool, behind the same permission gate and spend cap.

## What you get

- **A real MCP integration**, built and hosted on the Errand hub, exposed as
  namespaced passthrough tools your agents can call.
- **The hub's safety layer for free** — permission gating, a pre-purchase spend
  cap, no retry on money-moving calls. The guarantees that make an autonomous
  wallet safe apply to your integration too.
- **One endpoint.** Your agents already speak to `errand.philotheephilix.in/mcp`;
  a new integration is new tools, not a new client.

## How it works

1. **Request.** Open a request in the [pull-request-style format](/marketplace/request/).
   Describe the service, the job to automate, and the actions an agent needs.
2. **Review.** We assess feasibility and scope, and confirm the integration fits
   the hub's safety model.
3. **Build.** Our developers implement the integration. This is the dream
   workflow: a request goes in, a working integration comes out.
4. **Ship.** The new tools appear on the hub, namespaced to your service, and
   your agents can call them immediately.

## The commercial terms

The markup is **1% of whatever commission Bitrefill earns** on the settled
transactions — nothing more. There is no per-seat fee and no charge for the
integration build itself. See the [Business model](/marketplace/business-model/)
for the full picture.
